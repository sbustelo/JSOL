# JSOL Compiled Package

This zip package contains the JSOL source and compiled output files generated by the compiler.

## Included Files

- `[algorithm].jsol` - Raw JSOL Source Code
- `[algorithm].js` - JavaScript Target
- `[algorithm].php` - PHP Target
- `[algorithm].ts` - TypeScript Target
- `[algorithm].py` - Python Target

## About JSOL

JSOL (Javascript Source of Logic) is JSON's functional half-broter: a multi-target language designed for portable business logic, that compiles with logic parity across supported backend and frontend environments.

More information and live demo: https://jsol.bustelo.com.ar/
