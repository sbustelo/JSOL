# Interactive Visual REPL

**Live demo:** https://jsol.bustelo.com.ar/ — all examples are preloaded and interactive.

* * *

To run these examples quickly and interactively on your localhost PHP server, you can use the JSOL interpreter.

<img src="../assets/interpreter/repl-luhn-example.png" width="100%" alt="JSOL REPL Interpreter">

## Using the JSOL REPL Interpreter ##

Copy the `interpreter/interpreter.php` file into this `examples/` directory, and access it from your browser.

The REPL will scan the subdirectories, parse the metadata of the .jsol files, and allow you to modify inputs and see outputs in real-time as if it were a spreadsheet.
